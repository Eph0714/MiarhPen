Why: Apple only allows building/signing iOS apps on macOS with Xcode. That's an Apple platform restriction, not a Flutter limitation — there is no tool, flag, or workaround on Windows that produces an installable iOS build. I genuinely can't do this from here.

Your options:

Use a Mac you (or someone you know) has access to. Copy the MiarhPen project folder over, then on the Mac:

Install Xcode + Flutter, run flutter pub get, then flutter build ipa (needs an Apple Developer account, free tier works for sideloading to your own device for 7 days, paid $99/yr for permanent installs/TestFlight).
Or simplest for just testing on your own iPhone: open ios/Runner.xcworkspace in Xcode, plug your iPhone into the Mac via cable, select it as the run target, sign in with your Apple ID under Xcode's Signing & Capabilities, hit Run — installs directly, no App Store needed.
No Mac available — use a cloud Mac build service (Codemagic, Bitrise, GitHub Actions with a macos-latest runner, etc.).
